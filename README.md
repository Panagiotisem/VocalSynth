VocalSynth: Real-Time Voice Synthesizer and Vocal Trainer

Περιγραφή:
Το VocalSynth είναι ένα σύστημα ψηφιακής επεξεργασίας σήματος (DSP) γραμμένο σε MATLAB, το οποίο μετατρέπει την ανθρώπινη φωνή σε συνθετικό ήχο σε πραγματικό χρόνο
και περιλαμβάνει εργαλείο εξάσκησης φωνής.

Χαρακτηριστικά :

1. Pro Synth Engine

2. Real-Time Pitch Detection: Χρήση του αλγορίθμου Normalized Correlation Function (NCF) για σταθερό εντοπισμό της συχνότητας.

3. Custom Waveforms: Υποστήριξη για 4 τύπους κυματομορφών, συμπεριλαμβανομένου μοντέλου βιολιού με προσθήκη αρμονικών και θορύβου δοξαριού.

4. DSP Controls: Ενσωμάτωση Vibrato (LFO 5.5Hz), Glide (Portamento) και μετατόπιση οκτάβας.


Vocal Trainer :

1. Εργαλείο εξάσκησης φωνής με επιλογή νότας στόχου.

2. Οπτική ανατροφοδότηση απόκλισης συχνότητας.

3. Χρήση προσθετικής σύνθεσης για βελτίωση της ακουστότητας χαμηλών συχνοτήτων (Missing Fundamental Effect).


GUI :

1. Αναπτύχθηκε προγραμματιστικά με MATLAB και ενσωμάτωση HTML/CSS.

2. Δυναμικό περιβάλλον με στρογγυλεμένα πάνελ και αυτόματη προσαρμογή μεγέθους (Auto-Expand).


Οδηγίες Εγκατάστασης :

Απαιτείται το MATLAB.

Απαιτείται το Audio Toolbox για τη λειτουργία του μικροφώνου (audioDeviceReader).

Κατεβάστε το αρχείο vocal_synth17.m και εκτελέστε το.
